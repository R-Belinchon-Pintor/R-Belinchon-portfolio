Sobre R. Belinchón

Este espacio presenta la obra de R. Belinchón en formato digital, con una navegación limpia y una estética de galería. La web está preparada para seguir creciendo: se pueden añadir títulos reales, técnicas, medidas, series, años, precios, estado de venta o textos curatoriales cuando quieras.

Ahora mismo la colección aparece organizada como portfolio visual para facilitar la contemplación de cada pieza y el contacto directo con el autor.

Qué se puede añadir después

Esta primera versión ya está lista para publicar. En la siguiente iteración se puede incorporar:

Fichas completas de cada obra
Precios o estado: disponible, reservado, vendido
Biografía más amplia del artista
Instagram, catálogo PDF o formulario de encargos
